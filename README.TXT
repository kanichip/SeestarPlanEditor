Seestar 撮影プラン (SeestarPlanEditor)
====================================

デスクトップ版 Stellarium で天体と撮影範囲を確認しながら、
Seestar の望遠カメラ用撮影プランを作成する Windows アプリです。
対応機種は S30 / S50 / S30 Pro / S50 Pro です。

■ 起動方法

1. ZIP で受け取った場合は、フォルダーごと展開してください。
2. SeestarPlanEditor.exe をダブルクリックします。Python のインストールは不要です。
   _internal フォルダーは実行ファイルと同じ場所に置いてください。
   別の PC へ移す場合は、README.TXT や licenses を含むフォルダー全体をコピーします。

■ Stellarium の準備

1. 同じ PC でデスクトップ版 Stellarium を起動します。
2. F2 →「プラグイン」→「Remote Control（リモートコントロール）」で
   「起動時に実行」を有効にし、Stellarium を再起動します。
3. プラグインの設定でサーバーを有効にします。
   標準ポートは 8090 です。このアプリは認証なしのローカル接続を使用します。

■ 撮影プランの作成

1. アプリ左上で Seestar の機種を選び、プランの開始時刻を設定します。
2. Stellarium で天体を選び、アプリの「選択天体を取得」を押します。
3. 撮影時間（分）、LP フィルター、必要に応じて回転角や画角倍率を設定し、
   「反映」を押します。対象を追加するときは 2～3 を繰り返します。
4. リストの行はドラッグで並べ替え、ダブルクリックで再編集できます。
   各対象の開始時刻は、リストの順に撮影時間を積算して計算します。
   翌日 01:30 は 25:30 と入力します。導入やフォーカスの時間は自動加算されません。
5. 「ファイル」→「保存」（Ctrl+S）で JSON を保存します。
   保存したプランは「ファイル」→「開く」（Ctrl+O）で再編集できます。
   更新時の上書きを避けるため、プランはアプリのフォルダー外に保存してください。

■ Seestar への取り込み

・共有 QR
  「Seestar」→「共有QR」で内容を確認すると、ZWO クラウドへアップロードできます。
  スマートフォンの Seestar アプリ V3.4.1 以降で QR コードまたは共有リンクを
  読み取り、時刻と構図を確認して本体に設定してください。
  リンクを知っている人はプランを取得でき、サービス側に削除機能はありません。

・本体へ直接転送
  PC と Seestar を同じネットワークに接続し、「Seestar」→「接続」で
  本体の IPv4 アドレスを入力します。接続後、「Seestar」→「プラン転送」で
  接続先と開始時刻を確認して送信します。転送はプランの実行開始を兼ねます。
  開始時刻が過去の場合は、すぐに撮影が始まることがあります。

回転フレーミングはモザイク撮影範囲の設定です。S30 Pro 実機での反映と、
回転角の符号・基準方向は未検証です。Seestar アプリに取り込んだ後は
フレーミング画面で構図を確認してください。
